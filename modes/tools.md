# 特殊附魔與工具

下列功能可能需要指定權限、身分組或活動資格：

* `/ce`：開啟特殊附魔介面。
* `/tinker`：開啟附魔回收介面。
* `/blacksmith`：開啟鐵匠介面。
* `/gkit`：開啟套裝介面。
* `/ceat`：將主手支援的礦物轉成可食用版本。
* `/rename <名稱>`：重新命名主手物品。
* `/imageframe`：查看圖片地圖功能說明。
* `/qa`：查看武器工藝與商店。

功能內容、價格與權限可能隨活動或身分組調整，請以遊戲內介面顯示為準。

使用高價材料前，建議先以一般物品確認操作流程。
