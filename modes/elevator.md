# 電梯

電梯是特製的界伏盒，放在不同樓層的相同位置就能快速往返。

## 合成方式

在工作台放入 8 個羊毛包圍 1 顆終界珍珠：

|      |        |      |
| ---- | ------ | ---- |
| 羊毛 | 羊毛   | 羊毛 |
| 羊毛 | 終界珍珠 | 羊毛 |
| 羊毛 | 羊毛   | 羊毛 |

* 每次合成產出 1 個電梯，最多可堆疊 16 個。
* 使用哪種顏色的羊毛，就會做出對應顏色的電梯。

## 使用方式

在不同樓層的相同 X、Z 座標放置同色電梯，即可建立電梯。

* 站在電梯上跳躍：前往上一層。
* 站在電梯上蹲下：前往下一層。
* 蹲下並右鍵電梯：開啟電梯設定。

## 使用限制

* 上下樓層必須使用相同顏色的電梯。
* 樓層距離沒有上限，中間隔著方塊也沒關係。
* 目的地需要保留足夠的站立空間，被擋住時無法傳送。

若無法移動，請確認兩個電梯位於相同的 X、Z 座標且顏色相同。
