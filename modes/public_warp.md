# 公共傳送

`/pwarp` 打開傳送點清單

`/pwarp <名稱>` 傳送到傳送點

`/pwarp set <名稱>` 在您所在地點設定傳送點

`/pwarp remove <名稱>` 移除傳送點

`/pwarp list` 列出您的傳送點

`/pwarp amount` 查看您的傳送點數量

`/pwarp rate <rate>` 評價傳送點

`/pwarp lock` 鎖定傳送點

`/pwarp reset -Re` 重新設定傳送點位置

`/pwarp rename  <原名稱> <新名稱>` 重新命名傳送點

`/pwarp setowner player>` 轉移傳送點
