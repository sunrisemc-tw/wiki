# 語音聊天

日出伺服器使用 **Simple Voice Chat** 提供近距離語音聊天。安裝對應模組後，靠近其他玩家就能直接講話，不用另外開 Discord。

## 安裝模組

1. 用你慣用的啟動器（如 Modrinth App）開啟你的遊戲設定檔。
2. 搜尋 **Simple Voice Chat**（作者 henkelmax）並安裝。
3. 版本請選擇與**你的遊戲版本相同**的版本（例如 `2.6.20+26.1.2`），伺服器端目前為 **2.6.20**。
4. 重新啟動遊戲，確認模組有載入（Mod Menu 可查看）。

> 支援 Fabric / Forge / NeoForge / Quilt。

## 連線方法

1. 照平常方式連上伺服器（`sunrisemc.tw`）。
2. 進遊戲後左上角會出現**語音圖示**，代表語音已連線——不需要輸入任何指令。
3. 語音是**近距離制**：與玩家距離 **48 格內**才聽得到，耳語範圍 24 格，距離越遠聲音越小。
4. 預設**按住 Caps Lock** 說話（可在「選項 → 控制 → 按鍵綁定」修改）。
5. 按 **V** 開啟語音設定：選麥克風裝置、測試麥克風、調整音量與發話方式（按鍵發話 / 聲控）。
6. 按 **N** 可暫時停用語音。

### 語音群組

伺服器已啟用語音群組功能：按 V 開啟語音選單建立群組，組員**無論距離多遠**都能通話，適合分散在不同地點的隊友。

## 故障排除

| 問題 | 解法 |
|---|---|
| 沒有語音圖示 / 圖示是灰色的 | 模組沒裝成功或版本不符。確認 Simple Voice Chat 有載入、版本對應你的遊戲版本。 |
| 顯示「版本不相容」 | 伺服器端是 2.6.20，請安裝相同或更接近的版本。 |
| 聽得到別人，但別人聽不到你 | 按 V 檢查麥克風裝置與音量，先用「測試麥克風」確認；確認有按住發話鍵。 |
| 聽不到任何人 | 檢查喇叭/耳機裝置、遊戲音量與系統音量；按 V 測試輸出。 |
| 聲音斷斷續續 / 爆音 | 多為網路延遲：關閉其他吃網路的程式，或到 V 選單調整音訊封包門檻與輸出緩衝。 |
| 連不上語音（圖示一直轉圈） | 語音走獨立的 UDP 通道（24454，對外經 frp 24456），嚴格的防火牆/路由器會擋 UDP；可換網路或關防火牆測試。 |
| 距離很近卻聽不到對方 | 雙方都要安裝模組才能通話；確認對方也有裝。 |
